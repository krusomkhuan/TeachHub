# เก็บไฟล์บนเซิร์ฟเวอร์ และดาวน์โหลดสำรองไว้ในพีซี

ระบบใช้ฐานข้อมูลและโฟลเดอร์ `uploads/` บนเซิร์ฟเวอร์ ไม่มีการเชื่อมต่อที่เก็บไฟล์ Google Drive ไม่อ่านไฟล์ `config/drive_token.php` และไม่ต้องตั้งสิทธิ์ไฟล์โทเค็น

## ใช้งาน

1. อัปโหลดไฟล์งานตามปกติ ระบบเก็บลงเซิร์ฟเวอร์
2. ผู้ดูแลเปิด **สำรอง / กู้คืนข้อมูล** แล้วกด **สำรองข้อมูล**
3. ดาวน์โหลด ZIP ที่สร้างมาเก็บในคอมพิวเตอร์พีซี ภายในมี `database.sql`, `manifest.json` และ `uploads/` ครบทุกหมวด
4. สำรองอัตโนมัติรวมไฟล์ด้วยเสมอ ไฟล์อัตโนมัติเก็บบนเซิร์ฟเวอร์และต้องดาวน์โหลดมาเก็บในพีซีด้วยตนเอง

ZIP ไม่รวม ZIP สำรองเก่าและไฟล์ Log เพื่อไม่ให้สำรองวนซ้ำ ไม่มีการดาวน์โหลดเข้าพีซีอัตโนมัติจากเบราว์เซอร์

## ไฟล์เดิมที่เคยเก็บภายนอก

ไฟล์ที่ยังไม่อยู่บนเซิร์ฟเวอร์ไม่สามารถรวมใน ZIP ได้ ระบบจะแจ้งจำนวนไฟล์ขาดและไม่รายงานว่าสำรองครบ

เปิด **ไฟล์บนเซิร์ฟเวอร์** (`admin/drive.php` คง URL เดิมเพื่อรองรับสิทธิ์เจ้าหน้าที่เดิม) ดูรายการชื่อไฟล์และตำแหน่งที่ขาด ดาวน์โหลดไฟล์เหล่านั้นจากที่เก็บเดิมด้วยตนเอง หากได้ ZIP ให้แตกไฟล์ก่อน แล้วใช้ฟอร์มนำเข้าเป็นชุด โดยคงชื่อไฟล์เดิม ระบบตรวจชื่อ ขนาด ชนิดไฟล์ และไม่เขียนทับไฟล์ที่มีอยู่แล้ว

อีกทางหนึ่งนำไฟล์กลับผ่าน File Manager/FTP ตามโฟลเดอร์ `uploads/` ที่แสดง เมื่อไฟล์ครบจึงสำรอง ZIP ฉบับเต็มได้ ระบบไม่ลบข้อมูลหรือไฟล์ต้นฉบับที่เก็บภายนอก

## การติดตั้งอัปเดต

นำไฟล์จากชุดอัปเดตไปทับโดยรักษาโครงสร้างโฟลเดอร์เดิม ไม่ต้องนำเข้า SQL ไม่ต้องอัปโหลดหรือแก้ `config/db.php` และไม่ต้องลบข้อมูลเดิมในฐานข้อมูล

## การตรวจสอบ

- ตรวจ PHP syntax ทุกไฟล์ที่แก้
- ทดสอบไฟล์สำรองรวมไฟล์งานบุคลากรและไฟล์เดิมที่นำกลับ กู้คืนเนื้อหาได้ตรงกัน
- ทดสอบไฟล์ขาด การนำเข้าชื่อ/ขนาดผิด และการปฏิเสธตำแหน่งหรือไฟล์สคริปต์
- การทดสอบใช้ฐานข้อมูลจำลองและไฟล์ชั่วคราว ยังต้องตรวจบนเซิร์ฟเวอร์จริงหลังอัปโหลด
